# Saugi – Demo

Kinderfreundliches Ein-Finger-Spiel (Arbeitstitel „Saugi“). Ein kleines Wesen mit Saugnapf-Füßen läuft von selbst nach rechts.

**Spielen:** https://hasanbeg99.github.io/saugi-demo/

- **Halten** (Finger irgendwo aufs Spielfeld, PC: Leertaste): Saugi saugt sich an der Decke fest und läuft kopfüber.
- **Loslassen:** Saugi plumpst im Bogen auf den Boden.
- **Der Kniff:** Die Decke hält nicht überall. **Loch** = nichts zum Festsaugen, Saugi fällt trotz Halten. **Eis** = rutschig, Saugi wird schneller und rutscht nach kurzer Zeit ab. **Honig** = klebt fest, macht aber langsam.
- 3 kurze Level (Dschungel, Unterwasser, Weltall), Sterne nach gesammelten Beeren, sanftes Zurückprallen statt Game Over, Endlos-Modus mit 3 Herzen.
- Figuren mit Beeren freischalten (feste Preise, kein Zufall).

Eine einzige Datei (`index.html`), keine externen Abhängigkeiten, Töne per WebAudio erzeugt.
